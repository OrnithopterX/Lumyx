# Lumyx
An open-source LiDAR based 3D scanning platform focused on accessibility, flexibility, and ease of use.

Lumyx (loom - ex) captures the last year of my efforts to make a truly accessible 3D scanning system. All the software is open-source, and the machinical parts are mostly 3D printable. This is just the beginning!

# Building your own LUMYX

The .STEP and .STL files can be found on printables: (https://www.printables.com/model/1623868-lumyx-a-diy-3d-scanner).

If you want to produce your own remix, the original Onshape file can be found [here](https://cad.onshape.com/documents/dd8d982ba8502859204ee528/w/a78d61cbd94c6390059afb15/e/765d05a98b8357067b07b750). 

The all Arduino code can be found under the "releases" tab. 

The wiring schematic pdf can be found in the main branch. 

# Using LUMYX

The scans are saved as .OBJ point clouds, which can be opened in [Blender](https://www.blender.org/) for analysis.
